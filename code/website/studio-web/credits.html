ABOUT KLARA

A preview of
possibility.

Klara combines a person photo and a clothing photo to create an AI-generated preview. It does not predict physical fit, and it can change colours, faces and details outside the clothing.

Your images

Only use photos you have permission to upload. Images are processed on the project’s Google Cloud server in the United States. Inputs and results remain on that server until the project owner removes them. Images are not sent to a third-party image-generation API. Each visitor can access their own generated results; the project owner can administer stored images.

Project & model

Created by Anas Mhana for a data-science course project. This is a noncommercial research demonstration. The live studio uses CatVTON / CatVTON-MaskFree, by the CatVTON authors, under CC BY-NC-SA 4.0. The live model includes Klara’s trained self-attention weights from the course experiment (63 training cases, 200 updates). Research metrics were evaluated at 384 by 512 pixels; the studio generates at 768 by 1024, where the same quality improvement has not been established. Upstream models retain their own licences. No endorsement by the source authors is implied.
